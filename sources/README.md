# 講義原文の正本と照合ゲート

- `sources/lessons/25.md`, `26.md`, `27.md` に**チャットで実際に実施した講義本文**を保存する。確認問題、回答、採点結果は含めない。
- ファイル先頭に `<!-- SOURCE_STATUS: VERIFIED_ORIGINAL -->` を付けるのは、元チャットと全段落・表・コード・図の一致を確認した場合だけ。
- 原文のSVGはSVGマークアップをそのまま保存し、公開HTMLにも同じSVGを入れる。再描画、テキスト図への置換は不可。
- `python scripts/check_lesson_fidelity.py --lessons 25 26 27` で原文とHTMLを比較する。原文未登録、検証印なし、未照合フラグ残存、文章の欠落・順序変更、SVGの欠落・改変は不合格。
- GitHub Actions `SC Lecture Source Fidelity` は変更時に自動実行。**現時点では原文ファイル未登録なので不合格が正しい動作**。合格になるまで「全文照合完了」とは表示しない。
- この検査は正規化した本文とSVGマークアップの機械照合であり、レンダリング結果の視覚検査、意味上の改変検出、原文の出所確認を完全に自動化するものではない。人手での原文確認も必須。
- 進捗表・得点はこの照合処理の対象外。教材修正で変更しない。
