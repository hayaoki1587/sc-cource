1. 到達目標・参考書・学習優先度

VLANは物理的には同じスイッチを使用しながらネットワークを論理的に分離する技術です。SC試験では、何の通信が遮断され、何の通信は許可され得るのか、VLANを分けただけでは防げない攻撃は何かを判断することが重要です。

  1. VLANとブロードキャストドメインの関係を説明できる。
  2. ポートベースVLANとタグVLANの違いを理解する。
  3. アクセスポートとトランクポートの通信を読み解ける。
  4. 異なるVLAN間の通信に必要な仕組みを説明できる。
  5. VLAN間の不正通信、設定ミス、VLANホッピングへの対策を記述できる。

参考書：『徹底攻略 情報処理安全確保支援士教科書 令和7年度版』第3章3-2-1「LAN」pp.191〜193（VLAN、ポートベースVLAN、タグVLAN、IEEE 802.1Q、ブロードキャストドメイン、過去問と解説）。関連：第5章p.333「VLANでの対策」。アクセスポート、トランク、ホッピング、ACL、設定例は講師の試験対策補足です。

優先度範囲目安
A：必須VLANの仕組み、タグ、VLAN間ルーティング、アクセス制御、設定ミス75%
B：理解補助MACアドレス学習、ARP、トランク、ネイティブVLAN20%
C：発展VLANホッピングの細部、Q-in-Qなど5%

2. VLANが必要になる理由【A】

総務部、経理部、開発部のPCが同じL2スイッチ・同じVLANに接続されているとします。この場合、同じブロードキャストドメイン内のブロードキャストフレームは原則として各ポートへ転送されます。総務PCがARP要求を送ると、経理部や開発部のPCにも届きます。

VLANによる分離がない構成
  総務PC ─┐
  経理PC ─┼── L2スイッチ（同一VLAN）
  開発PC ─┘

総務PC → ARP要求（宛先MAC FF:FF:FF:FF:FF:FF）
       → スイッチ → 経理PC・開発PCにも届く

ARP要求はブロードキャストです。業務上関係のない部門にも不要な通信が届き、マルウェアがブロードキャストを使って周囲を探索する際の対象が広がりやすくなります。ただしARPが届くこと自体が情報漏えいや感染を意味するわけではありません。

同じスイッチ上で総務をVLAN 10、経理をVLAN 20、開発をVLAN 30に分けると、VLAN 10で発生したブロードキャストは通常VLAN 20や30へ転送されません。

VLAN対応L2スイッチ
  ├─ VLAN 10：総務部PC
  ├─ VLAN 20：経理部PC
  └─ VLAN 30：開発部PC
  ※ ブロードキャストはVLANごとに分離

VLANは物理的な接続形態とは独立してブロードキャストドメインを論理的に分割する技術です。

用語意味
ブロードキャストドメインブロードキャストフレームが届く範囲
コリジョンドメインイーサネットの衝突が発生し得る範囲
VLAN主にブロードキャストドメインを論理的に分割する

現代のスイッチングイーサネットでは各ポートが通常独立し、全二重通信では衝突自体が発生しません。VLANの主目的を「コリジョンの防止」と説明するのは不適切です。

3. ポートベースVLAN【A】

ポートベースVLANはスイッチの物理ポートごとに所属するVLAN IDを設定する方式です。

ポート機器VLAN ID
1総務PC-A10
2総務PC-B10
3経理PC-A20
4経理PC-B20
5開発PC-A30
6開発PC-B30
7〜8未使用未割当・無効化

ポート1と2は同じVLAN 10に属し、同じIPサブネットに適切に設定されていれば通常のL2通信ができます。ポート1と3は別VLANなので、L2スイッチだけでは原則としてフレームを転送しません。

VLAN 10
 PC-A：192.168.10.11/24
 PC-B：192.168.10.12/24

VLAN 20
 PC-C：192.168.20.11/24
 PC-D：192.168.20.12/24

VLAN IDはL2の識別番号、IPアドレスはL3のアドレスです。通常はVLANごとに別IPサブネットを割り当てますが、VLAN ID 10が必ず192.168.10.0/24を使う規則はありません。

4. タグVLANとIEEE 802.1Q【A】

1階と2階にスイッチがあり、どちらにも総務部と経理部があるとします。スイッチ間の1本のケーブルでVLAN 10と20を運ぶには、フレームがどのVLANに属するかを識別する必要があります。IEEE 802.1QではイーサネットフレームにVLANタグを付加します。

1階 スイッチA ═══ 1本のトランクリンク ═══ スイッチB 2階
 総務 VLAN10      タグ VID=10 / VID=20       総務 VLAN10
 経理 VLAN20                                  経理 VLAN20

フレーム概念：
[宛先MAC][送信元MAC][802.1Qタグ][タイプ][データ][FCS]
フィールド役割
TPIDタグ付きフレームを示す。通常0x8100
PCP優先度情報（3ビット）
DEI廃棄適格性（1ビット）
VIDVLAN ID（12ビット）

タグは通常4バイトです。12ビットで0〜4095を表せますが、通常のVLAN IDとして使えるのは1〜4094で、0と4095は特別な用途・予約値です。試験では細かなビット配置より、タグによって異なるスイッチ間でもVLANを識別できる点が重要です。

5. アクセスポートとトランクポート【A】

アクセスポートは通常1つのVLANに属する端末を接続するポートです。PCは通常802.1Qタグを意識せず、スイッチが受信ポートの設定から所属VLANを判断します。

PC-A ── タグなしフレーム ──→ アクセスポート
                              → VLAN 10として処理

トランクポートは複数のVLANのフレームを1本のリンクで伝送します。受信側はタグのVIDを読み、適切なVLANに所属させます。

スイッチA ════ トランク ════ スイッチB
            VID=10 フレーム
            VID=20 フレーム
比較アクセスポートトランクポート
主な接続先PC、プリンタなどスイッチ、VLAN対応機器など
VLAN数通常1つ複数
フレーム通常タグなしタグ付きが基本
所属VLANの判断ポート設定タグのVIDなど

トランクだからといってすべてのVLANを通す必要はありません。VLAN 10と20だけが必要なら、管理用VLANなど不要なVLANを許可しないことが重要です。

ネイティブVLAN（B）：802.1Qトランクでは設定によって特定VLANのフレームをタグなしで扱う場合があります。両端のネイティブVLAN設定が不一致ならタグなしフレームが意図しないVLANに所属する問題が起き得ます。後述のVLANホッピングにも関係します。

6. VLAN間通信とL3ルーティング【A】

VLAN 10とVLAN 20はL2で分離されますが、L3スイッチやルータでルーティングすればIP通信できます。例えば総務PC 192.168.10.11/24から経理サーバ192.168.20.50/24へ通信する場合です。

VLAN 10（192.168.10.0/24）       VLAN 20（192.168.20.0/24）
 総務PC 192.168.10.11                 経理サーバ 192.168.20.50
            └──── L3スイッチ（VLAN間ルーティング）────┘
  1. 総務PCは宛先が自分のサブネット外と判断する。
  2. デフォルトゲートウェイ（例192.168.10.1）へフレームを送る。
  3. L3スイッチが宛先IPアドレスを確認する。
  4. ルーティングテーブルを参照しVLAN 20側へ転送する。
  5. 経理サーバへIPパケットが届く。

これはL2スイッチがブロードキャストを別VLANへ通しているわけではなく、L3機器がIPパケットを別ネットワークへルーティングしています。

VLANを分けるだけでアクセス制御にはなりません。一般社員VLAN 10と機密サーバVLAN 20を分けても、L3で自由にルーティングできるならアクセスできる可能性があります。制限にはACLやファイアウォールが必要です。

7. ACLによるVLAN間アクセス制御【A】

一般社員用VLAN 10から経理サーバ192.168.20.50へのHTTPSだけを許可し、SSHなど不要な通信は禁止したいとします。

送信元宛先通信処理
VLAN 10経理サーバTCP/443許可
VLAN 10経理サーバTCP/22拒否
VLAN 10経理サーバその他不要な通信拒否

TCP/443はHTTPS、TCP/22はSSHの代表的なポートです。Web画面を使う必要はあってもサーバへSSHログインする必要はないなら、必要な通信だけを許可します。

ALLOW 192.168.10.0/24 -> 192.168.20.50 TCP/443
DENY  192.168.10.0/24 -> 192.168.20.50 ANY

これは製品固有のコマンドではなく概念的な擬似設定です。実際にはACLの適用方向、評価順序、戻り通信、IPv6も考慮します。

科目B答案例：「一般社員用VLANから機密情報サーバへの不要な通信を遮断するため、VLAN間のルーティング経路にACLを設定し、業務に必要な宛先・ポート番号だけを許可する。」

8. MACアドレス学習とARP【B】

L2スイッチは受信フレームの送信元MACアドレスを学習し、転送先を判断します。VLAN対応スイッチでは通常VLAN IDとMACアドレスを組み合わせて管理します。

VLANMACアドレスポート
10AA:AA:AA:AA:AA:011
10AA:AA:AA:AA:AA:022
20BB:BB:BB:BB:BB:013
20BB:BB:BB:BB:BB:024

同じMACアドレスが登録されているからといって別VLANへフレームを転送することはありません。通常のARP要求はL2ブロードキャストなのでルータがそのまま別VLANへ転送しません。異なるVLANの相手へIP通信するときは、通常、相手サーバのMACアドレスではなくデフォルトゲートウェイのMACアドレスをARPで調べます。

9. VLANのセキュリティ効果と限界【A】

VLANは異なるVLANへのブロードキャストを分離し、不要な通信が他VLANへ広がることを抑え、端末群ごとのアクセス制御の単位を明確にできます。しかしVLANはファイアウォールそのものではありません。

項目VLANだけで実現できるか
ブロードキャストドメインの分割できる
異なるVLANへのL2ブロードキャスト転送の抑止できる
VLAN間のIP通信を必要に応じて許可L3機器が必要
VLAN間の不要なIP通信を制限ACL・FW等が必要
同一VLAN内の感染を完全防止できない
端末認証・本人確認VLANだけではできない
通信内容の暗号化VLANだけではできない
VLAN 10
 ├─ 感染PC
 ├─ 正常PC-A
 └─ 正常PC-B

同じVLAN内で必要なL2通信が許可されていれば、感染PCは他端末へ通信を試みられます。VLANを導入しただけで感染拡大が完全に防げるわけではなく、端末側の防御や適切なアクセス制御を組み合わせます。

10. VLANホッピング【A・C】

VLANホッピングは、意図されたVLANの境界を越えて別VLANへ不正通信しようとする攻撃の総称です。代表例はスイッチスプーフィングとダブルタギングです。

スイッチスプーフィング

攻撃者がスイッチを装い、不適切な自動トランク設定を悪用してトランクリンクを成立させようとします。すべてのスイッチで成立するわけではなく、自動交渉機能や設定条件に依存します。

攻撃者PC → トランク自動交渉を悪用 → スイッチ
          → 本来許可されないVLANのタグ付きフレームを送ろうとする

対策：端末接続ポートを明示的にアクセスポートに設定し、不要なトランク自動交渉を無効にします。

ダブルタギング

802.1Qタグを二重に付け、ネイティブVLANなどの処理を悪用して意図しないVLANへフレームを届けようとします。成立には特定の設定・タグ処理条件が必要です。

[外側タグ：VLAN A][内側タグ：VLAN B][フレーム]
 → 特定条件で外側タグが除去
 → 内側タグが別区間で解釈されることを悪用

対策：ネイティブVLANを適切に設計し、一般端末を所属させない、トランクの許可VLANを限定するなど。試験では二重タグによる境界回避とトランク設定の適正化を理解すれば十分です。

11. VLANの設定ミスによる事故【A】

事例1：トランクで不要なVLANを許可

必要なVLANは10と20だけなのに、実際の許可VLANが10、20、30、40になっているとします。30が機密システム用なら意図しない場所へ延伸される可能性があります。対策は許可VLANを必要最小限にすること。ただし延伸だけで直ちに全機密情報へアクセスできるわけではなく、接続条件やL3制御にも依存します。

必要なVLAN：10,20
実際の許可VLAN：10,20,30,40

事例2：端末接続ポートを誤ったVLANに割り当て

来客用VLAN 30のはずのポートを社内用VLAN 10に割り当てると、来客端末が社内L2セグメントに参加し、社内ブロードキャストを受信したり通信を試みたりできます。対策はポート割当ての修正と端末認証・アクセス制御です。

事例3：VLAN間ルーティングが全許可

一般社員VLAN 10と管理VLAN 99を分離していてもL3で通信制限がなければ管理機器へIP通信できる可能性があります。対策はACLやFWで不要な通信を拒否することです。

12. 設定とログの読み方【A】

次は製品固有ではない単純化した設定例です。

interface port1
  mode access
  access vlan 10

interface port2
  mode access
  access vlan 20

interface port24
  mode trunk
  allowed vlan 10,20,99

port1はVLAN 10のアクセスポート、port2はVLAN 20のアクセスポート、port24はVLAN 10・20・99を通すトランクです。port24の接続先に管理用VLAN 99が不要なら設定を見直します。

2026-10-18 10:15:00
src=192.168.10.25
dst=192.168.99.10
protocol=TCP
dst_port=22
action=ALLOW

送信元が一般社員VLAN 10、宛先が管理VLAN 99の機器なら、一般社員端末から管理機器へのSSH通信が許可されたと読み取れます。禁止ポリシーならL3スイッチやFWのアクセス制御を調査します。ただしALLOWだけでSSHログインに成功したとは断定できません。通信許可と認証成功は別です。

13. 科目Bでの答案作成ポイント【A】

問われる内容答案の要点
VLAN分割の効果ブロードキャストドメイン分離と不要通信の抑制
VLAN間で通信できる理由L3スイッチ・ルータによるルーティング
VLAN間の不正アクセス対策ACL・FWで必要最小限の通信許可
トランク設定の問題不要なVLANが許可されている
端末接続先の誤設定誤ったVLAN所属による通信範囲の拡大
VLANホッピング対策不要な自動トランク禁止、タグ・ネイティブVLAN設定の適正化

不十分な答案：「VLANでネットワークを分離する。」

改善した答案：「一般社員用VLANと管理用VLANを分離したうえで、VLAN間のルーティング経路にACLを設定し、一般社員端末から管理用機器への不要な通信を遮断する。」

何を防ぐため、どの経路で、何を制御するのかを明確にします。

14. 重要事項の整理と発展学習

  • VLANはL2の論理的な分割であり、ブロードキャストドメインを分ける。
  • ポートベースVLANはポート設定で所属VLANを決める。
  • IEEE 802.1QはタグでVLAN IDを識別する。
  • アクセスポートは通常1VLAN、トランクは複数VLANを扱う。
  • VLAN間のIP通信にはL3スイッチやルータが必要。
  • VLAN間のアクセス制限にはACL・FW等を組み合わせる。
  • VLANは端末認証・暗号化・マルウェア対策の代わりにはならない。

C：任意の発展学習として、Q-in-Q（IEEE 802.1ad）、プライベートVLANの細かな仕様、ホッピングの実装依存の成立条件、ベンダー固有のトランク交渉プロトコルなどは今回の必須範囲から外します。
